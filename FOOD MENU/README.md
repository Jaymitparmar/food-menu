# 🍴 Bites Food Menu

A simple and responsive **restaurant food menu website** built using HTML5, CSS3, and Bootstrap 5.3.3.

The website displays a restaurant navigation bar, food menu categories, food cards with ratings and prices, a shopping/cart button, reservation button, newsletter subscription section, social media links, and footer navigation.

---

## 📌 Project Overview

**Bites Food Menu** is a restaurant menu webpage designed with a clean and modern layout.

The project includes:

- Restaurant navigation bar
- Bites logo and branding
- About Us, Menu, Reviews, Blog, and Contacts links
- Shopping basket icon
- Reserve Table button
- Food menu categories
- Food product cards
- Food images
- Star ratings
- Food prices
- Add to Cart buttons
- Newsletter subscription form
- Social media icons
- Footer with useful links
